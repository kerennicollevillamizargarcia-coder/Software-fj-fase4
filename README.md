# Sistema Integral de Gestión - Software FJ (Fase 4)
Proyecto de programación orientado a objetos para gestionar clientes, servicios (reservas de salas, alquiler de equipos y asesorías especializadas) y reservas sin uso de bases de datos, incorporando manejo avanzado de excepciones y registro de eventos o errores en un archivo de logs.
## Nota de desarrollo
Actividad desarrollada de manera individual para cumplir con la entrega de la Fase 4.
